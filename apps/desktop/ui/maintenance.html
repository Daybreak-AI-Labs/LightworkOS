If an update fails

    
If an update stops partway, Windows puts the previous version back automatically. Repair installation reinstalls your current version. Neither of these changes or restores your work.

    
Going back to the previous version together with your saved work is only possible after an update that saved a restore point first. Otherwise, ask your administrator for help.
