# Getting help

Help with Lightwork comes from its maintainers and community, on a
best-effort basis.

## Read the documentation

The documentation is published at https://daybreak-ai-labs.github.io/LightworkOS/
and its source is in [`docs/`](docs/). For a problem with your installation,
run `lightwork doctor` first: it checks the configuration, provider keys, the
sandbox and the world database, and suggests a fix for each problem it finds.

## Ask a question

Ask usage and design questions, or share what you are building, in
[GitHub Discussions](https://github.com/Daybreak-AI-Labs/LightworkOS/discussions).
Search existing discussions first; your question may already have an answer.

## Report a bug or request a feature

Open an [issue](https://github.com/Daybreak-AI-Labs/LightworkOS/issues/new/choose)
and choose the bug report or feature request template. A bug report needs the
output of `lightwork doctor`, the steps that reproduce the problem, the version
or commit you are running, and your platform. Remove API keys and other secrets
from anything you paste.

## Report a security vulnerability

Do not open a public issue. Follow [SECURITY.md](SECURITY.md) to report it
privately.

## Contribute a fix

If you can fix the problem yourself, see [CONTRIBUTING.md](CONTRIBUTING.md).
