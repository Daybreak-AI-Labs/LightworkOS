# Supervised knowledge index rebuilds

Enable Bounded search index rebuilds in Settings, Memory & learning, or the knowledge installer step. An administrator reviews the exact collection, current model identity, passage count, provider cost ceiling and elapsed-time limit. The Knowledge library records progress, offers cancellation after the current batch, and keeps the existing index until one atomic compare-and-replace publishes the complete replacement. Current authority and policy are checked before each batch and again before publication. Source changes refuse publication.

Jobs and shadow-vector checkpoints are private workspace/account records. Closing the page does not cancel a job. Refresh rebuild progress after disconnect. After server interruption, Continue after an interruption locks the existing job, verifies current source/model/limits and resumes saved batches; it never creates a replacement job automatically. An interrupted publication is reconciled against its recorded result fingerprint. Cancellation requests cannot claim reversal of a replacement that already published. Archive finished rebuild removes its temporary vectors while retaining the durable operation receipt, so retrying the same operation cannot start another rebuild.

Built-in deterministic and local sentence-transformer embedders have a zero-dollar embedding-provider ceiling; hardware costs are excluded. Local models must already be available. Deterministic indexing is an explicit offline/testing choice, never an automatic fallback. Rebuilding does not change provider settings.

Direct standard Voyage and OpenAI text embedding models with captured price evidence support hosted rebuilds. Review binds the exact endpoint, model, price evidence and expiry, collection, configuration revision and limits. Each batch reserves the maximum accepted input token count at the reviewed standard rate through both Budget and the native provider/organization cost authority before dispatch. This is a rate-based admission ceiling, not a guarantee of the vendor invoice. Taxes, negotiated agreements and storage-service costs are excluded. The current evidence expires after 2026-12-05; expired or unsupported contracts refuse new paid dispatch. A custom gateway's price is never inferred from a familiar model name.

The provider's native billed input count is validated and recorded at the exact reviewed rate. A missing/malformed usage receipt, different returned model, lost response or incomplete accounting acknowledgement stops further dispatch and keeps an unconfirmed receipt. The same job cannot resend that paid batch. A provider-reported overrun is recorded and stops subsequent batches. Progress shows confirmed observed charges and unresolved reservations separately. An administrator must inspect provider usage before explicitly reviewing a different rebuild.

Paid checkpoints seal vectors and cumulative accounting together, bound to the original account/workspace, job, source, model and review. Recovery can reuse that completed batch without another request. Atomic publication includes a unique marker derived from the reviewed job and complete vectors, so pre-publication interruption cannot masquerade as success even when rebuilding the same model. A completed publication can be verified after its dispatch price/deadline expires. Credential/configuration changes and source edits stop the next paid batch without publishing over changed content.

Cohere `embed-v4.0` currently has no supported reviewed standard-price contract. The current official pricing page exposes newer Embed 5 pricing; that rate is not substituted for Embed 4, nor are reseller prices used. Obtain current first-party rate/usage evidence or a separately verified agreement before enabling that paid path. This refusal changes no deployment setting or credential.

Administrator limits default to 10,000 passages, 300 elapsed seconds and a $5 embedding reservation. Settings and the installer expose the cost limit; zero allows local computation only. Limits are bounded at 100,000 passages, one hour and $1,000, plus fixed 32 MiB text / two million vector-scalar workspace limits. A durable deadline survives process death; downtime consumes the remaining allowance. Hosted transport timeouts use the lesser of 60 seconds and remaining time; HTTP timeout phases and an already running local model are not an absolute process-kill deadline. Time and cancellation are checked at safe boundaries between batches of at most 64. SQLite and pgvector require their existing atomic source compare-and-replace support. Other stores refuse unsafe partial rewrites.

The typed Copilot knowledge adapters use the same native review, operation receipt, authority, cancellation and recovery service. Registration is integrated with the shared product-operations registry.

Live providers, installed-model performance and distributed publication are not qualified. Cost and recovery messages use the English fallback.
