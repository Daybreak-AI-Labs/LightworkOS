# Employee activation

`/get-started/employee` composes five job guides from enabled suites and the
named caller's current authority. `features.employee_activation` controls the
journey. Administrators approve available jobs in All settings; installer
choices write `dashboard.employee_activation_jobs`. A workspace can only narrow
the installation catalog. Selecting a job never grants a role or tools.

A private encrypted draft records the sample-versus-real choice, provided text
or exact connected-document reference, and human acceptance criteria. Incomplete
source selection can be saved while Connections is repaired; its return link
opens the same draft. Connected documents are fetched only on explicit launch
through the existing scoped discovery service and attachment validation pipeline.
The task uses ordinary configured routes, rate limits, budgets and submission
receipts. No provider configuration or credential changes are required.

An original draft identity recovers its existing task without repeating admission.
Inputs become immutable once task admission begins. A missing response is not a
reason to create a new identity or retry paid work automatically. The current task
and native controls remain the source of execution status.

Human acceptance binds the exact current result fingerprint; a result edit or
state change invalidates displayed completion. Practice results stay labelled as
fictional and never become live evidence. A reviewed result can hand off to a
private reusable workflow draft with a new source placeholder. Original source
files, connection bindings and result text are excluded. Workflow publication
and scheduling remain separate native reviews.

The shared Copilot registry offers current state, draft creation/editing, reviewed
launch, acceptance and reusable-draft handoff using these same services. Protected
connector source selection remains in the native picker; opaque fetch references
are excluded from conversational result details. Copilot action families still
require the installation's existing opt-in.

Live provider calls, source fetches and the installed browser journey are not
qualified.
