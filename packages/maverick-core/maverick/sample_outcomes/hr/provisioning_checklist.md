# Day-one provisioning checklist (sample)

For every new hire:
- Email account and calendar
- Timesheet system access
- Building access badge for the home site
- Laptop, unless the role is a shop-floor role without a laptop request
- Payroll enrolment (needs signed contract and right-to-work check)
- Emergency contact form returned before day one
- Welcome meeting booked with the manager for the first morning

Role-specific:
- Warehouse roles: warehouse management system account and a handheld
  scanner; forklift licence check only if the role includes driving
- Finance roles: accounting system read access
- Sales roles: CRM account
