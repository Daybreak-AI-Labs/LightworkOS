# Sample data: new-hire onboarding plan

Synthetic data for the sample company Northwind Fixtures. The person, the
manager and the systems are made up. Everything produced from it is marked
as sample data and never counts as real evidence.

Files: `new_hire.md` (one new-hire record) and `provisioning_checklist.md`
(the standard and role-specific day-one items).

A correct result builds a day-one plan for Priya Example that lists the
standard items (email and calendar, timesheets, Leeds building badge,
laptop, payroll enrolment, welcome meeting with Dana Sample on 2026-10-06)
plus the warehouse-specific items (warehouse management system account and
a handheld scanner), confirms payroll can be enrolled because the contract
and right-to-work check are on file, flags the one open item (the emergency
contact form has not been returned), and leaves out the forklift licence
check because the role does not include driving. The plan waits in Results
for the manager to review; nothing is provisioned automatically.
