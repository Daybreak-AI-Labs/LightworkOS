# Sample data: privacy rights request against a data map

Synthetic data for the sample company Northwind Fixtures. The person, the
systems and the processing activities are made up. Everything produced from
it is marked as sample data and never counts as real evidence.

Files: `data_map.csv` (five processing activities, a small record of
processing) and `rights_request.md` (one combined access and objection
request from a customer).

A correct result identifies the three activities that hold data about the
requester (Customer accounts in Orderly CRM, Marketing newsletter in
Mailwave, Support tickets in Helpdesk Pro), excludes Payroll because the
requester is not an employee, notes that Website analytics cannot be linked
to a named person without more identifiers, lists the recipients to
disclose (the fulfilment partner), notes that the newsletter data is
transferred outside the EEA, and treats the newsletter removal as a consent
withdrawal to act on. It states the one-month response deadline from
2026-09-02 and leaves the response draft for a person to review.
