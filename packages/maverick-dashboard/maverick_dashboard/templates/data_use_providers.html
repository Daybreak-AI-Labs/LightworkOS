About this page’s safeguards

Lightwork prepares every database change itself from the saved decision and checks the decision again just before applying it; nobody can type database commands here. Removing a connection is permanent and keeps its history; to reconnect, create a new connection. These connections have not yet been tried against a live customer account, so test with a non-production table first.
