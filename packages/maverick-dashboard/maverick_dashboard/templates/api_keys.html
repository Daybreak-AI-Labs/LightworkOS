What the key may do

Only the permissions your role allows are offered. A key can never do more than you can. Task keys cannot decide approvals in the shared queue or paused workflows; approval keys cannot run task actions. Full administrator access includes work and activity-record actions. No key can create, rotate or revoke access keys.

Service accounts

A service account is a named identity for a program. It holds keys and a role but cannot sign in. Disabling one stops all of its keys at once.
