Run learning now

Lightwork usually learns overnight. Use these to run it now, check the result, or go back.

Learn from recent work

Reviews recently finished tasks, writes lessons from repeated problems and turns repeated successes into skills. A saved point is made first, so you can go back.

Learning requires signed activity records. Review the activity record setting.

Go back to a saved point

Restore the learned information covered by a saved point. Completed work and changes in connected services are not undone.

Check whether anything useful was lost

Compares past tasks against the saved point above: which ones Lightwork now has a lesson for, and which ones it lost. Nothing is re-run and no AI is used.

Compare recorded results

Enter two scores for each task, from 0 to 100 percent. This compares your entries; it does not verify how tasks were assigned or prove that learning caused a difference. For planned cases and reviewed outcomes, use Workflow pilots.
