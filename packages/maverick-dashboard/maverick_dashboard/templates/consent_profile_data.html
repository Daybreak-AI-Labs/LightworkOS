How it works

  1. Add the questions as “Extra questions” on the Banner and preference center page and publish them.
  2. Set up a question set for a website key. A second person approves it.

About this page’s safeguards
  • The person who writes a question set or plan cannot approve it.
  • Answers are limited to the choices you published; people never type free text, and nothing is guessed about them.
  • Question sets are tied to exactly what your banner publishes, so a changed banner needs a new set.
