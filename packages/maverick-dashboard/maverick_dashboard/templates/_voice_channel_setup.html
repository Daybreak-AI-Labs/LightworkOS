Enter the function in your phone service

Use the provider's ordinary form editor for these fields. Select a value below to copy it. No program or structured document needs to be entered in Lightwork.

Vapi

In the saved assistant's Tools form, add this function and its required Text field. Use the address above as its Server URL. In Integrations → Server Configuration, add a Custom Credential with Authentication Type Bearer Token, Header Name Authorization and Include Bearer Prefix on. Enter the private Call check key saved in Lightwork, then select that credential for the saved assistant's server. Make sure tool-calls are sent to this server. Ordinary transcript and status notifications do not start work.

Retell

In the saved agent's Functions form, add a Custom function with the values above. Choose POST and enter the address above. Add an Authorization header containing Bearer followed by a space and the same private Call check key. Keep Retell's option to send only the function's fields turned off, and keep automatic retries off. Use the full call details: a request without Retell's matching recorded function identity is refused.

Bland can place outgoing calls through the existing integration. Incoming Bland conversations are not supported here.

A returned answer confirms the saved Lightwork result, not that the provider spoke it or the caller heard it. If a connection is interrupted, the same provider call reads its original result; it does not repeat completed or unconfirmed work. Start a separate request only after checking any earlier changes.
