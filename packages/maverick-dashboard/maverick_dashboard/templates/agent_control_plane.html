What each action does

  • Pause stops an agent or person from doing any more work until someone resumes them.
  • Resume lets a paused agent or person work again.
  • Isolate (administrators) locks an agent away so it cannot be resumed by accident. End isolation lifts it.
  • Limit tightens what an outside agent may do: its risk level, spending, time and tools. It never loosens limits.
About this page's safeguards

After every change Lightwork re-reads the real state of each agent and shows you what it found. A change is only reported as done once it has been confirmed. Group actions work on the exact list you reviewed; if anything changed in between, Lightwork refuses and asks you to review again. The emergency stop is reported as active only after Lightwork has checked it took effect. Each action is written to the agent's history; if that record could not be written, the result says so.
