About this page’s safeguards
  • Lightwork can scan Amazon S3, Azure Blob Storage, Google Cloud Storage, Snowflake, ServiceNow and Microsoft Entra.
  • A scan only covers the source and limits you set. Finding nothing does not prove there is no personal data.
  • Text, web pages, spreadsheets saved as text and similar files are read. PDFs, Office files, images, archives, audio and video are listed as not read, never treated as checked.
  • Lightwork keeps only fingerprints and counts of what it finds, never the personal data itself.
  • Approved findings update Lightwork’s own data map. You can separately review and confirm their use in a saved Data Use dataset. Nothing is changed in the scanned systems.
