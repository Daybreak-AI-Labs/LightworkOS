Lightwork's services

Start, stop or restart the parts of Lightwork that run alongside this app. These include profiling, the core activity monitor and the model proxy while their setting is on. A service your IT team runs some other way isn't shown here and isn't affected.

Version and release parts

Which version of Lightwork is installed, and whether every part of the full release is present and working.

Release checks

Record how fast and how costly tasks are today, then after an update compare against that baseline to see whether anything got worse. Measured from tasks finished in the last 30 days.

Setup checks

Checks, without contacting anyone, that this installation is set up to run tasks and to run assurance reviews. The same checks appear on Get started.

Whole configuration

Every setting that differs from the built-in defaults, its current value and where it comes from. Passwords and keys show only whether they are set. Change settings in All settings.

Records database

Waiting database updates, and whether a shared database keeps each workspace's records separate.

Older records without a workspace

Records made before workspaces were turned on belong to no workspace. Assign them to one so they stay visible once workspaces are kept separate in the shared database.

Moving records to the shared database

What Lightwork has learned

Moves improvements learned on this computer into the shared records so every installation uses them. The old files are kept as backups. Safe while Lightwork is running.

Chat-agent task records

Moves a workspace's records of work requested by outside agents into the shared database. This can only run while Lightwork is stopped, so it is scheduled here and runs the next time Lightwork starts.

Consent records

Copies each workspace's consent records from files on this computer into the shared consent database chosen in All settings. Choosing that database doesn't move anything by itself, so run this after Lightwork restarts. Each part is copied whole or not at all, only where the shared database is still empty, and the files here are kept. Safe while Lightwork is running.

Upkeep

  • Message receipts Clears the stored text of chat messages that were delivered long ago. The record that each was delivered is kept.
  • Connection components Prepares the components other systems use to connect, so nothing has to be built while Lightwork runs.
  • Encryption key fingerprint Identifies the encryption key your IT team gave this installation, without revealing it.
  • Local AI model server Shows what Lightwork would start to run AI models on this computer. Nothing is started.
