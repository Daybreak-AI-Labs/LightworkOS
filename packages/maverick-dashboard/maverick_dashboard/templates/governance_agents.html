About this page's safeguards

Assistants only read records Lightwork already holds; this page never accepts pasted evidence, workspace choices, credentials or destinations. Every result waits for a person to review it. Carrying out an action is off unless a policy allows it. It needs two different people to approve, and is recorded so it can be checked later.
