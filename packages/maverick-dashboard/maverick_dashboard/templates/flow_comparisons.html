Scope and recovery

Select up to five real runs from the latest 200 retained runs of the exact current publication. Each version uses its own saved included workflows, all belonging to the same account. The limits are sixteen included workflows, sixty-four total defined steps and eight levels. Comparisons support taught rules, directly named text, whole-number or yes/no inputs, ordinary value assignments and simple routes that compare values directly. Grouped inputs, expanding or transformed templates, cycles, retries, time calculations and secret lookups are outside this scope. Original inputs stay within 8 KB. A ten-second local allowance and a limit on step checks stop repeated included-workflow calls at step boundaries. An individual bounded calculation may return before the check can stop it. Local timings include recording overhead. If a reply is lost, check the original retained comparison; it does not repeat the work. Changing an included workflow makes an earlier comparison historical for release review. Removing it, replacing its owner or withdrawing its teaching sources can make the retained comparison unavailable.
