About this page's safeguards
  • Uploaded files are read within size limits and are not kept. The text read from them is not stored either.
  • Lightwork checks your workspace, your permissions, the document's registration and the review criteria before reading anything.
  • Every result waits for a different, authorized person to approve or reject it.
  • Which file types can be read depends on how Lightwork is set up. Unsupported or unsafe files are refused.
