How to set one up

  1. Choose a chat app below and tick Turn on.
  2. Paste the details that app gives you. Each field says where to find it. Connection secrets are stored securely and never shown again. Leaving a secret blank keeps what's saved. A blank permitted-people list stops everyone from using that app.
  3. Press Save, then Test connection. Check message delivery below and apply changed details before sending a test.
  4. Message Lightwork from that app. Requests are handled the same way as tasks started here, and replies come back in the same conversation.
