    Before changing company sign-in

    Register this Lightwork installation with your company's sign-in provider. Enter its application details here; passwords are sealed and never displayed again. Preserve an administrator's working way back in. Provider reachability alone cannot establish that replacement access works: Lightwork refuses a switch that removes your only sign-in.

    Single sign-on provider details can use the provider's secure web address. Certificates, server file choices, and longer lists have their existing protected controls under People & access. Proxy sign-in requires your company to make that proxy the sole route to Lightwork. This page cannot establish that network boundary.

    When a server or workspace controls a value, this page shows it as fixed. Changes here cannot replace that higher authority. New policy affects new work; it does not rebuild an already running work area.
