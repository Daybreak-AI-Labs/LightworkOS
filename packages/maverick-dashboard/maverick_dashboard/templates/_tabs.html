``host_header(host)`` is the header a page shows when it hosts another page's job in one of its tabs: the host's title (a hero when ``host.kicker`` is set, else a plain heading), then the tab bar. ``host`` carries kicker, title, subtitle, lede, label, tabs and selected. Only tabs the person may open are passed in; the page checks the same access again. ``panel_tabs(...)`` is the same bar for views that are panels of one page (or filters of one list): each tab is a button, the selected one shows its panel, and the arrow keys select (``activation='manual'`` only moves focus, for a choice that loads data). ``items`` are ``(key, text)`` or ``(key, text, value)``; with ``data='sec-tab'`` each tab also carries ``data-sec-tab=""`` for the page's own script.
