Add it to another page

Copy the code below and give it to whoever looks after the page where the card should appear, such as your wiki or intranet team. It already points at this dashboard. Each viewer uses their own signed-in session and existing permissions. Do not paste an administrator access key into shared HTML.

Technical details (the code to paste) 
<script src="http://YOUR-DASHBOARD:8765/static/lightwork-analytics.js"></script>
<lightwork-analytics
    endpoint="http://YOUR-DASHBOARD:8765"></lightwork-analytics>

Host this alongside the dashboard so each viewer's session supplies their own access. A rejected request requires sign-in or an administrator's permission review, not a more powerful shared token.

Good to know

  • Works on pages served alongside Lightwork. For security, browsers only let the card load data from pages on the same address as this dashboard (or behind the same reverse proxy). A page hosted elsewhere will show a "blocked" message rather than your data.
  • Keep credentials out of shared pages. Legacy token attributes remain supported, but the token is readable by everyone who can inspect the page. Remove shared credentials and use individual sessions.
  • Sample and freshness. Task counts cover at most the latest 100 accessible tasks. The card labels its scope and last update; Refresh reloads it.
  • View-only. The card only reads data — it can't change anything, and it shows the error plainly if a request fails.
  • Already added somewhere? Cards added before Lightwork was renamed keep working unchanged.
